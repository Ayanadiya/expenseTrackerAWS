Expense Tracker App A full-stack Expense Tracker web application that helps users manage their personal finances with features like expense logging, premium membership, secure file uploads, and password reset functionality.

🔧 Tech Stack Backend: Node.js, Express.js

Database: MySQL, Sequelize ORM

Frontend: HTML, CSS, Bootstrap, JavaScript

HTTP Client: Axios

Authentication: JWT (JSON Web Tokens)

Cloud Storage: AWS S3

Email Service: SendInBlue API

Payments: Razorpay

🚀 Features ✅ User Authentication & Authorization

Register/Login functionality with JWT-based auth.

Secure routes for authorized users only.

📊 Expense Management

Add and delete expenses.

View expense history.

🌐 Premium Membership

Razorpay integration for secure payments.

Unlock premium features upon successful payment.

☁️ AWS S3 Integration

Upload and download reports securely to/from AWS S3.

🔐 Password Reset via Email

Integrated SendInBlue API to send password reset links with secure tokens.

📦 Sequelize ORM

Clean and efficient interaction with MySQL database using Sequelize.

📱 Responsive UI

Designed with Bootstrap for a responsive and user-friendly interface.
